# WiFi万能钥匙 Xposed 模块

WiFi万能钥匙 5.2.13 的 Xposed 模块，提供本地 SVIP 永久解锁、全模块去广告、底栏/工具栏精简等功能。

## 功能特性

### 核心功能
- **本地 SVIP 永久解锁**：无需订阅，自动解锁所有 SVIP 功能
- **全模块去广告**：移除开屏广告、列表广告、视频广告
- **底栏精简**：可隐藏底部导航栏中的视频、附近、福利等标签页
- **工具栏精简**：可隐藏首页工具栏中的垃圾清理、手机加速、网络测速等小组件

### 工具栏组件开关
支持独立控制以下工具栏组件的显示/隐藏：
- 垃圾清理
- 手机加速
- 手机降温
- 网络测速
- 网络加速
- 安全检测
- 快看
- 免费小说
- 游戏中心
- 更多

### 额外功能
- **青少年模式增强**：优化青少年模式体验
- **云控去除**：移除云控配置对功能的影响
- **实时状态同步**：模块设置与APP实际状态保持同步

## 技术信息

- **目标应用**：WiFi万能钥匙 5.2.13 (com.snda.wifilocating)
- **Xposed API**：libxposed API 101
- **开发框架**：Android Gradle + Kotlin
- **Hook 技术**：反射拦截 + 方法替换

## 安装说明

1. 确保设备已安装 LSPosed 或类似的 Xposed 框架
2. 构建本项目生成 APK：`./gradlew :app:assembleDebug`
3. 在 LSPosed 管理器中激活本模块
4. 选择目标应用（WiFi万能钥匙）
5. 重启目标应用

## 使用方法

1. 打开模块设置界面
2. 根据需求开启/关闭各项功能开关
3. 某些功能需要重启目标应用才能生效
